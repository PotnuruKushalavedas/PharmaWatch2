# PharmaWatch

## Introduction

PharmaWatch is a pharmacy management project used to manage medicine details, stock, and expiry dates digitally. It helps pharmacies and medical stores maintain records easily and reduce manual work.

---

## Features

* Add and manage medicines
* Track medicine stock
* Check expiry dates
* Search medicine details
* Easy-to-use system

---

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js / express.js
* supabase

---

## Modules

### 1. User Login

Used for secure login and registration.

### 2. Medicine Management

Add, update, delete, and view medicines.

### 3. Stock Management

Tracks available medicine stock.

### 4. Expiry Tracking

Shows medicines near expiry.

---

## Advantages

* Reduces manual work
* Saves time
* Improves medicine tracking
* Easy to maintain records
